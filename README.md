# Kniffel Block

Punkteblock für das Würfelspiel **Kniffel** als Web-App (eine `index.html`, React über CDN).

- Spieler anlegen (beliebig viele), Standardspieler in den Einstellungen speichern
- Klassischer Kniffel-Block: Einser bis Sechser, Bonus (+35 ab 63), Pasche, Full House, Straßen, Kniffel, Chance
- **Würfel in der App**: 5 Würfel, 3 Würfe, Würfel antippen zum Halten – danach zeigt die App für jedes freie Feld die Punkte
- Oder mit echten Würfeln spielen und Felder von Hand eintragen, streichen oder korrigieren
- Zusatz-Kniffel (+50 je weiterem Kniffel) optional
- Rangliste und Spielende-Popup, Spielstand bleibt im Browser gespeichert

Live: https://sampvp-cmyk.github.io/Kniffel-Block/ – in Safari „Teilen → Zum Home-Bildschirm“.
